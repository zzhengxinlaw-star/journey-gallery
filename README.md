# The Journey Gallery

A static HTML and CSS practical assignment that presents a sample Venice travel offer. The page includes a €100-per-person package, a May 2024 calendar, and a newsletter form mockup. The price, dates, and controls are for demonstration. The page has no checkout or newsletter service.

## Download or clone

On GitHub, select **Code → Download ZIP** and extract the archive. To clone with Git, run:

```sh
git clone https://github.com/zzhengxinlaw-star/journey-gallery.git
cd journey-gallery
```

## Run locally

Open the extracted or cloned folder and double-click `Untitled-1.html` to open it in a browser. Keep `Untitled-1.css` beside it. No installation or local server is required.

- `Untitled-1.html` contains the travel offer, calendar, and form.
- `Untitled-1.css` styles the page.
